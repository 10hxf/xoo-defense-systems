# xoo-defense-systems

Code associated with the study:

**Phylogeographic and functional assembly of population-level bacterial immunity**

This repository contains the custom data-processing script and workflow used for Coinfinder analysis of antiphage defense systems in *Xanthomonas oryzae* pv. *oryzae*.

See `coinfinder.md` for details.
